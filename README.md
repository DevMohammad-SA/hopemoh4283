# Mohammad Albuainain

**Backend developer — Python, Django, Linux.**
Final-year Computer Science student at Saudi Electronic University.

I build backend web apps, CLI tools, and small automations — usually in Python — and I run the Linux systems they live on: an Arch laptop, a Debian home server, and as much self-hosted infrastructure as I can reasonably maintain myself. Clean workflows (Neovim + terminal), maintainable code, projects that solve a real problem.

I write about all of it, in Arabic.

## Selected Work

**[Twibble](https://github.com/DevMohammad-SA/Twibble)**
A minimalist Twitter-like social app in Django — registration, posts, a follow graph, and a personalized feed built from it. My largest project, and the one I keep coming back to.

**[saqeel-resources](https://github.com/DevMohammad-SA/saqeel-resources)**
A static Arabic (RTL) resource site built for a youth-development charity, running on a Git-based CMS so non-technical volunteers can publish without touching the repo. Real users, real constraints.

**[dotfiles](https://github.com/DevMohammad-SA/dotfiles)**
My working environment — Neovim (Lua), Zsh, Tmux, and helper scripts. Maintained continuously rather than dumped once.

**[arch_system_maintenance](https://github.com/DevMohammad-SA/arch_system_maintenance) · [debian-system-maintenance](https://github.com/DevMohammad-SA/debian-system-maintenance)**
Bash automation for keeping Arch and Debian machines healthy — updates, orphaned packages, caches, leftover configs. Written for my own laptop and home server, and used on both daily.
